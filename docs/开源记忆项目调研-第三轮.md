## 0. 一句话结论

**能力面我们已经不缺（12 工具 / 9 页签 / 43 条契约 / 722 测试块 / 路线 18 个阶段全部有落地），
缺的是「造了没人用」的账：真注入没做、团队库字段没迁移、契约闸门没进 CI、开箱仍不可用。**
竞争面两条硬事实：① DSH 记忆插件是全生态最卷类目（官方目录 8655 条里 384 条是 memory 类），
「可治理」已被 6 家做出产品——**单独讲治理已不构成差异，必须与「团队 + 服务端 + ES」三个词一起说**；
② 仍没人占的空位只有两个：**服务端多人共享 + 一人一索引 + ACL（四词齐全者全目录 0 个）**、
**Elasticsearch 后端（memory 类 0 个用 ES）**。
本轮新借的机制集中在三处：**工具面工程化**（MCP 官方实测只改描述就 80%→100% 命中）、
**反馈真回流**（访问加权保持、记忆账本净收益算式）、**治理开关包**（默认只读 + 敏感硬黑名单 + kill switch）。

### 1.4 警示

- **治理正从差异点变成入场券**：memory-eternal 11-05 当天还在发版（先审后入 + 不可篡改审计 + 记忆账本），@bangbang-03 有 597 个测试（画像 + 红线 + 注入审计）。6~12 个月内「有审批有审计有面板」会变成默认预期。
- **mnemon 是本机既成事实**（月下载第一、19 个子包在 profile）：任何替换型方案都不现实，继续走「并存 + 各管一库」；可参考 dsh-memory-doctor 的共存策略（检测到别人就不注入）。
- **hindsight 必须持续跟踪**：唯一同时具备服务端多人 + 大厂背书 + 量化 benchmark 的对手（托管计费导向，但技术结论仍是「不替换 mnemon」）。
- AGPL 风险：OpenViking 主项目 AGPLv3 且带「禁止整体改写后再开源」条款——**可学机制，禁拷代码**；basic-memory / SillyTavern 同。

| P2-2 | **版本演化 diff 链** | Hy-Memory coding（零 LLM 附加每个版本真实 diff，保住被回滚版本） | supersede 现在只有新旧文本，没有「当时改了什么」；可先做轻量版（存 diff 摘要） |
| P2-3 | **检索自进化调参器**（带回归护栏） | SimpleMem EvolveMem | 我们有契约基线（43 条）是现成的 Guard 底座；但 LLM 诊断成本与误调风险要先估 |
| P2-4 | **目录/作用域检索 + 摘要先行** | OpenViking L0/L1/L2、MemPalace wing/room | 检索单位从条目上移到索引/域摘要——与我们的分盘星图天然契合，但要动聚合逻辑 |
| P2-5 | **learnings 三段模板 + 冲突检查** | Trail-Code（Decided/Tried/Watch out + `touches:` + `trail check`） | 对团队知识库的「约定类」记忆很贴；可先以文档规范试点 |
| P2-6 | **轻量读档位 + 续读指针** | `observationLimit=0` / bm_read max_tokens | 我们已有 detail=summary，补结构化「续读 offset」即可 |
| P2-7 | **工具注解**（readOnly/idempotent/destructive） | MCP #5349 官方已合并 | DSH 工具元数据层若支持则零成本；memory_save 同内容去重=事实幂等 |
| P2-8 | **persona↔记忆重合度体检** | @kira905 | 防同一件事写进两处；我们 persona/traits 与普通记忆无重合检查 |

### 明确不做（本轮再确认）

| 做法 | 理由 |
|---|---|
| 引图数据库 / 换存储后端 | 一人一索引 ACL 的隔离模型建立在 ES 上；第三份数据源=新的一类故障（第一轮已论证） |
| LLM 自动从对话抽取记忆 | CPU Ollama 成本不划算；显式保存语义质量更高（memU 反向的「agent 侧蒸馏」只做成本对照，不改架构） |
| 替换 mnemon | 既成事实（85k 月下载、19 子包在 profile）；继续并存 |
| 跟进专用记忆写入模型（Hy-Memory 30B） | 趋势信号，等生态成熟；只用 SDK 不用模型 |
| 全量原文路线（MemPalace） | 与「写入准入 + 蒸馏」是相反路线；其作用域检索与 audit 自评可单独借 |
